## Completed in this session

**VC-13 — Event Log & Transcript (`vault-transcript.js` + IDB v6):**
- `vault-idb.js` bumped to v6; `_ST_EVENTS = 'wf-events'` store added
- `captureEvent(sessionId, type, actorDid, payload)` — SHA-256 hash chain (WebCrypto),
  appends to `wf-events`, auto-enqueues `transcript.generate` job (dedup via `_txPendingJobs`)
- `generateTranscript(sessionId)` — full HTML+RDFa document from events (call/speech/data/revision segments, AmbiguityLog, RevisionHistory, DataSharingLog); job handler registered
- `annotateTranscript(sessionId)` — adds `resource=` attributes for SUBSTANCE_INTERACTIONS terms; job handler registered
- `saveRevision(sessionId, deltaText, correctedByDid, privateKey)` — Ed25519-signed delta stored in `wf-events` (seq=-1, type='revision')
- `vault-comms-call.js` wired: `captureEvent` at `call.start`, `call.end`, `data.request`
- `vault.html`: script tag added; 📄 View + 📦 Download buttons in queue job list for done transcript jobs; `_queueViewTranscript()`, `_queueDownloadPackage()` helpers

**VC-14 — Language Transcoding (`vault-comms-transcode.js`):**
- `detectAvailableTier()` → `'webspeech'` | `'local-llm'` | `'external-api'` | `null`
- `startRealtimeTranscription(stream, sessionId, langHint)` — WebSpeech API, emits `captureEvent('speech.segment')`, enqueues `transcript.transcode` job if lang ≠ vault lang
- `transcodeSegment(segment, targetLang)` — Tier 2: transformers.js `pipeline()`; Tier 3: user-configured external endpoint with explicit per-session consent gate
- `configureExternalApi(endpoint)`, `grantExternalApiConsent()`, `revokeExternalApiConsent()`
- `transcript.transcode` job handler registered
- `vault.html`: `wf:call` event listener starts/stops transcription; Translation settings panel in queue sheet (endpoint config, consent button, tier label); `_txcGrant()`, `_txcUpdateTierLabel()`

**VC-15 — Content Package (`vault-package.js`):**
- `buildPackage(sessionId)` — collects transcript HTML (from scheduler job result or fresh generate), events NDJSON, VP receipts; SHA-256 artefact hashes; JSON-LD manifest; enqueues `ots.submit` job
- `generateManifest(sessionId, artefacts, odrlPolicyRef)` — `wf:ContentPackage` JSON-LD
- `downloadPackage(sessionId)` — File System Access API zip (showSaveFilePicker) with fallback to individual file downloads
- `_pkgBuildZip(files)` — pure-JS ZIP builder (PKWARE APPNOTE 6.3, method 0 stored, no deps)
- `_pkgCrc32(buf)` — IEEE 802.3 CRC-32
- `ots.submit` job handler — submits manifest hash to OpenTimestamps calendar
- `package.build` job handler
- `vault.html`: script tag added; 📦 button in queue panel; `_queueDownloadPackage()` helper

**Session 14 — Buffer / Integration:**
- `vault-comms-call.js` `_callSetupDc`: added routing for `job_result/progress/error` → `schedHandleDesktopResult()`; `call_control` → `endCall/muteAudio/muteVideo`
- `connector/index.html`: demo auto-connect — `showQR()` saves to `localStorage('wf-demo-session')`; pair screen shows "📱 Open vault connect page" + "📋 Copy link" buttons; `teardown()` clears entry
- `webconnect.html`: auto-connect from `?sid=&relay=` URL params; calls `connectToSession()` directly (skips QR scanner)
- `vault.html`: `?v=6` cache-bust suffix on all local `<script src="js/...">` tags to prevent stale-cache issues in dev

## Decisions made

- `?v=6` cache-bust on all script tags replaces per-release versioning;
  bump to `?v=7` when the next IDB upgrade happens.
- Job offload uses `_callDc` (call DataChannel) not the pairing DC;
  this limits offload to active vault↔vault calls — acceptable for MVP.
- `buildPackage()` hashes raw bytes (fixed from initial TextDecoder approach).
- Demo auto-connect uses URL params (`?sid=&relay=`); localStorage stores
  the live session only while QR is visible, cleared on teardown.
- `transcript.generate` jobs use `JOB_TRIGGER.ALWAYS` (run locally, not offloaded).
