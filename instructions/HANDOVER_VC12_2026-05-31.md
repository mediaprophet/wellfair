## Decisions made this session

- `verifyGuestToken` is in-memory only (Map in vault-comms-call.js) — no IDB persistence needed since tokens expire with the call session.
- The call DataChannel (`_callDc`) doubles as the in-call data sharing channel — no separate protocol needed.
- Queue badge shows pending + running count; clears to hidden when both are 0.
- `_checkConditions` reads the page checkbox toggles (`sched-idle`, `sched-charging`, `sched-desktop`) if present — settings are not yet persisted to IDB (acceptable for VC-12; persist in a polish pass).
- `callSendData` / `callSendReceipt` silently no-op when `_callDc` is not open (e.g., in demo mode without an active call).
