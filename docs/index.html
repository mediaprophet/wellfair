What's in the vault

🛡 Privacy & Safety

  • Sanctuary Mode — hidden, double-encrypted workspace
  • Duress decoy — second PIN opens identical vault, fires silent alert
  • Dead Man's Switch — anonymous Nym alert on missed check-in
  • Evidentiary Export — signed VP + Bitcoin OpenTimestamps anchor

📞 Verified Communications

  • Caller gating — institutions prove identity before they can ring
  • Semantic Handshake — both parties sign what may be shared
  • Encrypted calls — vault↔vault or guest link, no install needed
  • Live data sharing — approve per section; every share gets a signed receipt

💊 Health Tracking

  • Medications — schedule, take/skip log, drug interactions
  • Diet log — macros, barcode scanner, Open Food Facts
  • Biometrics — Samsung Health CSV import via WebAssembly
  • RDF export — Turtle, SPARQL queries, SHACL validation

💳 Human-Centric Wallet

  • Lightning wallet — confidential transaction infrastructure
  • Nym Mixnet routing — messaging without IP correlation
  • No server — all data stays on your device
  • Anonymous notify — send alerts without revealing identity
